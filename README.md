# 낡아가는 배: 나루터의 시간

지학사 2022 개정 공통국어1 `1-(1) 서정 갈래의 이해` 연계 학습 게임 — **한용운, 「나룻배와 행인」 (『님의 침묵』, 1926)**

## 주요 특징
- **2.5D 수묵담채 디오라마**: 핸드페인팅 1926년 평저선(`boat-fresh` ↔ `boat-weathered` 노화 크로스페이드) + 커스텀 GLSL 수묵 강물 셰이더(여울·빗방울 파문·어조 색감 반응) + WebGL 불가 시 2D 폴백
- **내재적 통합 4대 메커니즘**: 역전된 내구도(헌신의 결 0~4), 느린 홀드·호흡 조작, 어조 조율판(원망/건조/원문 경어체), 대조의 저울 & 5연 수미상관 카메라 회귀
- **해석 개방 & 창작**: 3중 상징 렌즈(연인·1926년 조국·불교 고해/제도, 비채점) + 나만의 2행 은유 카드 + 제출용 통합 1장 PNG(`1080×1440`) & 수업 디브리핑 4선
- **교실 지원**: 교사 모드(`Shift+T` 또는 타이틀 로고 5회 연타), 음소거(`M`), 모바일(세로/가로)·태블릿·크롬북 반응형

## 로컬 실행
```bash
npm install
npm run dev
# http://localhost:5101/
```
