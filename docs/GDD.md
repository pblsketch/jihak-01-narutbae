## 2. 핵심 메커니즘과 절차적 수사학 (내재적 통합)

> **점검 질문**: *"「나룻배와 행인」의 학습 내용을 빼도 이 게임이 성립하는가?"* → **아니오.** 이 게임의 모든 규칙은 화자의 헌신·경어체 어조·대조 구조·수미상관·상징 다의성 그 자체로 작동한다.

### 2.1 메커니즘 ①: 역전된 내구도 — "낡아감 = 실패가 아니라 헌신의 결"
- **규칙이 주장하는 바**: 일반적인 게임에서 흙발·급류·눈비는 피해야 할 데미지이지만, 이 게임에서는 **피할수록(거부할수록) 시가 진행되지 않고, 받아 안고 버틸수록 선체가 낡아가며 시가 완성된다.**
- **HP 바·게임오버 전면 배제**: 화면 상단에는 체력바 대신 **4마디 목재 나이테(헌신의 결 0/4 → 4/4)**가 자리한다.
- **3D 목재 선체 노화 4단계**:
  - `결 0 (1연)`: 갓 띄운 소나무 평저선, 매끈한 연황색 나무 결
  - `결 1 (2연 전반)`: 배 바닥에 선명한 흙발 자국 텍스처 각인 (`흙발로 짓밟음` 수용)
  - `결 2 (2연 후반)`: 급한 여울의 물보라와 긁힌 물결 자국, 젖어 짙어진 소나무 판자
  - `결 3 (3연)`: 밤낮 바람과 눈비로 튼 나무 틈과 서리 흔적, 낡은 밧줄
  - `결 4 (4~5연)`: 깊게 낡아 검붉고 고아한 고재(古材) 질감 위에 은은한 금빛 세월의 결(시구 완결)

### 2.2 메커니즘 ②: 느린 홀드·호흡 조작 (2연 건너기 · 3연 기다리기)
- **확정 조작 철학**: 타이머 압박이나 반사신경 판정을 두지 않는다(`학습게임_설계이론.html` §8 질문 ② 준수). 스마트폰 세로·가로 어디서든 **한 손가락 꾹 누르기(터치 홀드) / 마우스 홀드 / `Space` 키 홀드**만으로 조작한다.
- **2연 `안고 건너기` 홀드**:
  - 얕은 물 → 깊은 물 → 급한 여울의 3구간을 건넌다.
  - 화면 중앙 하단의 **`[안고 버티기]`** 영역(또는 3D 배 자체)을 길게 누르면 나룻배가 물살 속에서도 행인을 흔들리지 않게 감싸며 앞으로 나아간다.
  - 도중에 손을 떼면(실패 상황) 게임오버 대신 물살에 배가 크게 출렁이며 *"물살이 거세어 배가 흔들립니다. 다시 당신을 안고 여울을 버텨 보세요."*라는 부드러운 안내가 뜨고, 진행도는 초기화되지 않고 이어서 건널 수 있다.
- **3연 `밤에서 낮까지` 호흡 기다림 홀드**:
  - `만일 당신이 아니 오시면` 자막과 함께 빈 나루터에 바람·눈비가 내린다.
  - 플레이어가 **`[기다리며 버티기]`**를 길게 누르는 동안 3D 하늘이 `초저녁 → 깊은 밤(눈발) → 새벽 안개 → 이른 낮`으로 천천히 회전하며, 배 위로 눈비가 쌓이고 목재가 낡아간다.
  - 손을 떼면 시간이 잠시 멈추고 *"눈비가 차갑지만, 나룻배는 나루를 떠나지 않습니다."* 문구가 스치며, 다시 누르면 이어서 낮까지 도달한다.

### 2.3 메커니즘 ③: 어조 조율기 (경어체 실험실)
- **동작 원리**: 2연·3연·4연의 핵심 시구에서 **3단 어조 스위치**를 직접 전환해 볼 수 있다.
  1. **원망·하대체** (`[어조 실험 — 원문 아님]` 청록 배지): 예) *"당신은 흙발로 날 짓밟아."*, *"물만 건너면 돌아보지도 않고 가 버리네."*
     - → 3D 강물이 탁한 붉은 회색으로 거칠게 일렁이고, 물결 파고가 높아지며, 음향이 날카롭고 불협화음으로 변한다.
  2. **건조 서술체** (`[어조 실험 — 원문 아님]` 청록 배지): 예) *"당신은 흙발로 나를 짓밟는다."*, *"물만 건너면 돌아보지도 않고 간다."*
     - → 3D 색감이 채도 빠진 회색빛으로 식고, 배와 행인 사이 거리가 멀어지며 건조한 정적이 흐른다.
  3. **원문 경어체** (`[원문]` 붉은 낙관 배지): 예) *"당신은 흙발로 나를 짓밟습니다."*, *"나를 돌아보지도 않고 가십니다그려."*, *"언제든지 오실 줄만은 알아요."*
     - → 3D 강물에 잔잔한 먹빛·쪽빛 윤슬이 퍼지고, 따스한 여명이 배를 감싸며 가야금·목탁 여운이 공명한다.
- **오개념 방지**: 변형 어조를 '오답 벌점'으로 처리하지 않고, *"어조를 바꾸니 화자의 마음이 원망/거리감으로 변했네요. 한용운이 끝내 선택한 경어체는 어떤 마음을 담고 있을까요?"*처럼 **비교 발견**을 유도한 뒤 원문 경어체로 확정한다.

### 2.4 메커니즘 ④: 대조의 저울 & 수미상관 복원
- **대조의 저울 (교과서 p.19 활동 6-(1) 직결)**:
  - 각 연에서 체험한 단서 칩 6개를 `'나(나룻배)'` 축과 `'당신(행인)'` 축에 탭-투-배치(또는 드래그)로 정리한다.
  - 2연 2개(`흙발로 짓밟음` / `안고 어떤 물이든 건너감`), 3연 2개(`바람·눈비 맞으며 밤낮 기다림` / `돌아보지 않고 가 버림`), 4연 2개(`날마다 낡아감` / `언제든지 오실 줄 믿음 — 시상의 전환`).
  - 배치할 때마다 화면의 대조 저울이 균형을 잡으며, 교과서 핵심 주제 문장이 한 조각씩 드러난다.
- **수미상관 카메라 회귀 (5연)**:
  - 1연 시작 시 저장해 둔 정확한 3D 카메라 위치·각도·화각(FOV)으로 5연에서 부드럽게 되돌아간다.
  - 구도는 1연과 100% 동일하지만, **선체에는 4단계 헌신의 결이 새겨져 있고 하늘에는 새벽 여명이 드리워져 있다.**
  - 플레이어가 1연의 두 행(`나는 나룻배 / 당신은 행인`)을 5연 빈 시집 자리에 직접 복원하고 마지막 마침표(`.`)를 찍으면 수미상관의 형식적 완결성과 운율이 완성된다.

### 2.5 메커니즘 ⑤: 3중 상징 렌즈(해석 개방) & 나만의 2행 은유 카드
- **3중 상징 렌즈 (비채점 · 해석 개방)**:
  - 본편(5연) 완주 후, 완성된 원문과 3D 나루터 위에 **세 장의 반투명 한지 렌즈**를 차례로 모두 겹쳐 읽는다(학습 누락 방지).
    1. **연인의 렌즈 (분홍·먹빛 한지)**: `당신` = 사랑하는 임 · `물/여울` = 사랑의 시련 · `나룻배` = 무조건적 희생과 기다림
    2. **조국의 렌즈 (쪽빛·1926년 한지)**: `당신` = 일제강점기 빼앗긴 조국(광복) · `물/여울` = 식민지 시대의 고난 · `나룻배` = 조국을 기다리며 헌신하는 독립 의지
    3. **불교의 렌즈 (금빛·연꽃 한지 — 지도서 p.38)**: `당신` = 구제해야 할 중생 / 부처 · `물/여울` = 고통과 번뇌의 고해(苦海) · `나룻배` = 중생을 건네는 제도(濟度)와 보시(布施)
  - 3장을 모두 확인한 뒤, **"오늘 나에게 가장 깊게 와닿는 '당신'의 얼굴은?"**에서 **1장을 선택**해 결과 카드의 **내 시선 인장**으로 찍는다. (채점 없음 · *"다른 시선을 고른 친구와 왜 그렇게 읽었는지 이야기해 보세요"* 안내)
- **나만의 2행 은유 카드 (교과서 p.18 활동 5 연계 · 원작 불침범)**:
  - 원작 본편과 분리된 독립 화면에서 교과서 활동 5의 3단 구조를 그대로 적용한다.
    1. **관계·원관념 고르기** (추천 칩: `나와 가족` / `나와 친구` / `나와 꿈` / `나와 학교생활` / `직접 입력`)
    2. **2행 은유 만들기**: `나는 [보조관념]` / `당신은 [보조관념]` (추천 시어 칩 탭 또는 키보드 자유 입력, 각 최대 18자)
    3. **유사성 한 줄 적기**: *"왜 그렇게 빗대었나요?"* (예: *"잠깐의 쉼을 주기 때문"*, 추천 문장 틀 제공 + 자유 입력, 최대 45자)
  - **낙관 찍기**: 1926년 『님의 침묵』 초판본 판형에서 영감 받은 한지 시집 카드 위에 내 이름(또는 별명) 붉은 낙관을 탭해 찍는다.

### 2.6 궁금증 보조 장치: '1926 나루터 세밀 관찰 5점' 도감
- 본편 1~5연의 3D 디오라마 안에 은은하게 반짝이는 **관찰 지점 5개**를 배치한다(필수 진행 조건이 아니므로 못 찾아도 진행 가능, 결과 화면에 `발견 n/5` 잠금 실루엣 표시로 호기심·친구 대화 유발).
  1. `[1연]` **소나무 평저선 판자 이음** (1920년대 전통 나룻배 고증)
  2. `[2연]` **짚신·검정 고무신의 흙발 자국** (1926년 행인 복장 고증)
  3. `[3연]` **나루터 나무 말뚝과 닳은 밧줄** (기다림의 공간)
  4. `[4연]` **거자필반(去者必返)의 물결** (불교적 진리 노트)
  5. `[5연]` **1연에 없던 마침표 하나(`.`)** (수미상관의 종결감)

### 3.1 씬별 세부 연출 및 상호작용 명세

#### [씬 0] 타이틀 & 1분 사전 도입 (1분)
- **3D 연출**: 이른 아침 안개 낀 1926년 조선 강변 나루터. 갈대와 버드나무가 천천히 흔들리고, 빈 목조 나룻배가 물결에 잔잔히 떠 있다.
- **UI**: 중앙 제목 《낡아가는 배: 나루터의 시간》, 부제 *"한용운, 「나룻배와 행인」 (1926)"*, `[나루터에 오르기]`(새로 시작) / `[이어서 건너기]`(저장본 존재 시).
- **사전훈련(15초 오버레이 카드 1장)**:
  - 3색 표식 안내: 붉은 낙관(`원문`), 한지 카드(`풀이·개념`), 청록 배지(`게임 연출·실험`).
  - *"이 게임에는 체력바와 게임오버가 없습니다. 낡아가는 것은 실패가 아니라 헌신의 결입니다."*

#### [씬 1] 1연 — 시점의 전환과 은유 설정 (2분)
- **3D 연출**: 강변 원경에 있던 카메라가 나룻배 선체 위로 천천히 내려앉는다(1연 기준 카메라 좌표 `CAM_STANZA_1` 저장 — 5연에서 정확히 회귀). 강 건너편 흙길에서 두루마기를 입은 행인(2D 빌보드)이 다가온다.
- **상호작용**:
  1. 나룻배와 행인을 각각 탭하여 `나 = 나룻배`, `당신 = 행인` 은유 짝짓기(풀이 예시 포함, 즉시 확인).
  2. 한지 해설 카드: *"비유 중 은유(A는 B)로 '나'와 '당신'의 관계를 설정합니다."*
- **원문 해금**: `나는 나룻배 / 당신은 행인` (붉은 낙관 표식, 마침표 없음 유지).

#### [씬 2] 2연 — 흙발 수용, 여울 홀드, 어조 조율기(시범) (4.5분)
- **3D 연출**: 행인이 짚신/고무신 흙발로 배에 오른다. 배가 출렁이며 나룻배 목재 위에 흙발 자국(결 1)이 찍힌다. 이어서 강 한가운데로 나아가며 수심이 `얕은 물(맑은 청록) → 깊은 물(짙은 남색) → 급한 여울(하얀 물보라·거친 파도)` 3단계로 변한다.
- **상호작용 순서**:
  1. **흙발 받아 안기**: 행인이 오를 때 배가 흔들리며 `[흙발을 받아 안기]` 버튼 등장(피하기 버튼 없음!). 탭하면 흙발 자국이 배 바닥에 새겨지고 **헌신의 결 1/4** 점등.
  2. **여울 안고 건너기 (느린 홀드)**: `[안고 버티기]`를 길게 누르면(`Space` 가능) 3구간을 순차 통과. 급한 여울 구간에서 파도가 높아지고 선체가 젖으며 **헌신의 결 2/4** 각인. (손을 떼도 초기화 없음, 부드럽게 이어서 진행)
  3. **어조 조율기 #1 (풀이 예시 시범)**: `당신은 흙발로 나를 [짓밟습니다].`에서 안내 멘트가 먼저 원망체(`짓밟아`)와 건조체(`짓밟는다`)를 눌러 보게 안내하고, 3D 강물이 거칠어졌다가 경어체(`짓밟습니다`)에서 잔잔히 공명하는 차이를 직접 확인한다.
  4. **대조의 저울 #1 (풀이 예시 시범)**: 2연 단서 2개(`흙발로 짓밟음` → 당신, `안고 어떤 물이든 건너감` → 나) 중 첫 번째가 자동 시범 배치되고, 두 번째를 학생이 직접 놓는다.

#### [씬 3] 3연 — 밤에서 낮까지의 기다림과 무정한 떠남 (4.5분)
- **3D 연출**: 행인이 건너편 기슭에 내리자마자 **뒤도 돌아보지 않고** 갈대숲 너머로 걸어가 사라진다. 이어서 `만일 당신이 아니 오시면` 가정 전환과 함께 하늘이 어두워지며 바람과 눈비 파티클이 쏟아진다.
- **상호작용 순서**:
  1. **밤에서 낮까지 기다림 (호흡 홀드)**: `[기다리며 버티기]`를 길게 누르는 동안 3D 조명이 `밤(눈보라) → 새벽(비·안개) → 낮(차가운 햇살)`으로 순환한다. 시간의 흐름(`밤에서 낮까지 = 언제나, 항상, 영원히`)을 체감하며 **헌신의 결 3/4** 각인.
  2. **무정한 뒷모습 관찰**: 물만 건너고 돌아보지 않는 행인의 뒷모습을 탭해 관찰.
  3. **어조 조율기 #2 (힌트 선택형)**: `나를 돌아보지도 않고 [가십니다그려].` — `가 버리네(원망)` / `간다(건조)` / `가십니다그려(원문 경어체 + 약간의 원망과 안타까움이 스민 담담한 탄식)` 비교. (원하면 `[힌트 보기]` 토글로 어미 `-시-`, `-ㅂ니다`, `-그려`의 뉘앙스 확인)
  4. **대조의 저울 #2 (힌트 축소)**: 3연 단서 2개(`바람·눈비 맞으며 밤낮 기다림` ↔ `물만 건너면 돌아보지도 않고 가 버림`)를 스스로 배치.

#### [씬 4] 4연 — '그러나' 시상의 전환과 날마다 낡아감 (2.5분)
- **3D 연출**: 가장 깊은 어둠과 눈비 속, 낡고 틈이 생긴 나룻배. 이때 강 수면 위로 붉은 낙관빛 시어 **`그러나`**가 떠오른다.
- **상호작용 순서**:
  1. **시상의 전환 점등**: 플레이어가 `그러나`를 탭하면 어둠 속 강 수면에 잔잔한 새벽 금빛이 퍼지며 분위기가 **체념에서 확신·희망으로 전환**된다.
  2. **어조 조율기 #3 (도움 걷어내기 — 자립)**: `당신이 언제든지 오실 줄만은 [알아요].` — 힌트 없이 `오겠지(불확실)` / `안다(단정)` / `알아요(부드럽고 확신에 찬 경어체)`를 비교하고 원문으로 조율.
  3. **거자필반(去者必返) & 결 4 완성**: *"떠난 사람은 반드시 돌아온다"*는 믿음의 한지 카드가 열리고, `날마다 날마다 낡아갑니다` 시구와 함께 선체 노화 4단계 **헌신의 결 4/4 완성**.
  4. **대조의 저울 완성 확인**: 2~4연 대조 축을 한눈에 확인하며 교과서 p.19 활동 6-(1) 핵심 주제(*"임에 대한 헌신적인 사랑과 기다림"*) 확정.

#### [씬 5] 5연 — 수미상관 카메라 회귀 및 인출 복원 (1.5분)
- **3D 연출**: 카메라가 배 위에서 부드럽게 물러나 **1연의 시작 좌표(`CAM_STANZA_1`)와 완벽히 동일한 강변 구도**로 회귀한다. 배경과 구도는 1연과 똑같지만, 나룻배에는 4단계 세월의 결이 새겨져 있고 하늘은 맑은 아침빛이다.
- **상호작용 (인출 연습)**:
  1. 빈 한지 시집의 마지막 5연 자리에 학생이 1연에서 배운 두 행(`나는 나룻배` / `당신은 행인`)을 시어 카드로 직접 복원하고, 마지막 **마침표(`.`)**를 찍어 마무리한다.
  2. **수미상관 비교 오버레이**: 1연 화면(새 배)과 5연 화면(낡은 배)이 나란히 반투명 비교되며, *"같은 구절이 돌아왔지만, 2~4연의 시간을 거친 뒤 읽는 '나는 나룻배 / 당신은 행인.'은 어떻게 다르게 느껴지나요?"*와 수미상관 3대 효과(**주제 강조 · 형태적 안정감 · 운율 형성**)를 제시한다.
  3. 전편 원문(1~5연) 전체 보기 버튼 상시 제공.

#### [씬 6] 3중 상징 렌즈 — 같은 시, 세 개의 얼굴 (2분)
- **3D + UI 연출**: 완성된 5연 원문이 중앙/좌측에 펼쳐지고, 하단(또는 우측)에 3장의 반투명 한지 렌즈 탭이 놓인다.
- **상호작용 (비채점)**:
  1. 세 렌즈(**연인의 사랑** / **1926년 조국·광복** / **불교의 중생 제도·고해**)를 하나씩 선택해 겹쳐 본다. 렌즈를 씌울 때마다 3D 나루터의 빛깔·문양 오버레이와 원문 속 `당신`, `물·급한 여울`, `나룻배` 위의 상징 주석이 실시간으로 바뀐다.
  2. 3장을 모두 겹쳐 읽으면 **비유(1:1 대응)와 상징(암시적·다의적 의미)의 차이**(지도서 p.30) 요약 카드가 짧게 뜬다.
  3. **내 시선 1장 인장 선택**: *"세 가지 얼굴 중, 오늘 나에게 가장 깊게 남은 '당신'의 시선을 하나 골라 결과 카드에 찍어 보세요."* (정답 없음 — 어떤 렌즈를 골라도 존중하는 해석 피드백)

#### [씬 7] 나만의 2행 은유 카드 & 결과·디브리핑 (2분)
- **나만의 2행 은유 카드 (원작 불침범 독립 화면)**:

## 4. 난이도 축, 스캐폴딩 & 실패 처리 설계

### 4.1 3대 난이도 축 (단계적 상승)
1. **시어·의미의 층위**: `직접 은유(1연)` → `행위 대조·경어체 어조(2~3연)` → `시상의 전환·불교적 함축 '거자필반'(4연)` → `구조적 회귀·수미상관(5연)` → `다의적 상징(3중 렌즈)` → `서정적 생산(2행 은유)`
2. **도움의 양(스캐폴딩 걷어내기)**: `자동 시범(1~2연)` → `선택형 힌트(3연)` → `힌트 없는 자립·인출(4~5연)`
3. **인지 활동 깊이**: `관찰·수용` → `비교·조율` → `분류·복원` → `다층 해석·창작`

### 4.2 장치별 풀이 예시(Worked Example) & 도움 걷어내기(Fading)

| 활동 | 1~2연 (시범 단계) | 3연 (도움 축소) | 4~5연 (도움 걷어내기 · 인출) |
| :--- | :--- | :--- | :--- |
| **느린 홀드** | 화면에 맥박 애니메이션 + "길게 눌러 안아 주세요" 안내 | 안내 문구 축소, 밤→낮 시계 링으로 직관 피드백 | 홀드 조작 종료, 시각 전환과 인출에 집중 |
| **어조 조율기** | 첫 문장(`짓밟습니다`)에서 원망체·건조체 차이를 1회 시범 가이드 | `[힌트 보기]` 버튼(선택)으로 `-가십니다그려` 뉘앙스 제공 | 힌트 비활성 기본, 학생 스스로 `알아요` 조율 |
| **대조의 저울** | 2연 첫 항목(`흙발로 짓밟음`) 자동 시범 배치 후 1개 직접 배치 | 3연 2개 항목 모두 직접 배치(1회 선택 힌트 가능) | 4연 완성 + 5연 1연 시구 빈칸 **직접 인출 복원** |

### 4.3 실패 처리 원칙 — "실패해도 전진한다"
- **게임오버 없음**: 2연·3연 홀드 중 손을 떼거나, 대조의 저울 배치가 틀리거나, 어조 조율기에서 원망체를 먼저 골라도 점수를 깎거나 처음부터 되돌리지 않는다.
- **부분 피드백(Partial Feedback)**:
  - 대조의 저울 오답 시: *"1개 항목의 자리가 바뀌었습니다. 시구에서 '나는'과 '당신은' 중 누가 한 행동인지 다시 살펴볼까요?"* + 해당 연 원문 문장 부드럽게 하이라이트.
  - 5연 수미상관 복원 오답 시: *"1연의 첫 두 행을 떠올려 보세요. 화자('나')와 청자('당신')의 순서가 중요합니다."*

## 6. 반응형 UX 및 화면 와이어프레임

### 6.1 4대 뷰포트 레이아웃 원칙
- **터치 타깃**: 모든 버튼·칩·조율 스위치는 최소 `44×44px` 이상, 버튼 간 간격 최소 `8px`.
- **Safe-area**: `viewport-fit=cover` 및 `env(safe-area-inset-*)` 적용으로 모바일 노치·하단 홈바 가림 방지.
- **2.5D 캔버스 비중**: Three.js 캔버스는 전 화면 배경(`100dvw × 100dvh`)으로 깔리고, HUD와 카드 패널은 시야 중앙의 나룻배·행인을 가리지 않도록 상단 슬림 바 + 하단/우측 카드 구조로 배치한다.

### 6.3 기술 경량화·폴백 및 사운드 사양
- **Three.js 2.5D 성능 예산**:
  - `renderer.setPixelRatio(Math.min(window.devicePixelRatio, 1.5))`, 그림자 맵 비활성(수묵담채 조명·안개 셰이더로 경량 대체), 파티클 수 모바일 120개 / 데스크톱 250개 이하 → 저사양 크롬북·스마트폰 60fps 목표.
  - **WebGL 불가 폴백**: WebGL 초기화 실패 또는 `webglcontextlost` 시 즉시 **2D Canvas/CSS 다층 패럴랙스 나루터 렌더러**로 자동 전환해 100% 동일한 게임플레이 보장.
- **Web Audio API 프로시저럴 사운드**:
  - 외부 MP3/WAV 파일 없이 Web Audio API로 잔잔한 강물 소리(필터드 노이즈), 바람/눈비, 어조 전환 음색(원망 불협/건조 무음/경어체 국악 5음계 여운), 낙관 도장음을 실시간 합성(로딩 0KB).
  - 교실 수업 배려: 상단 우측 `[🔊/🔇]` 음소거 토글 상시 노출 + 단축키 `M`. 음소거 상태에서도 화면 자막·파형 피드백으로 학습 손실 없음.

  - 타이틀 화면의 로고/제목 영역 **5회 연속 탭(클릭)** (모바일·태블릿 친화)
  - 또는 어느 화면에서나 키보드 **`Shift + T`** 입력
- **기능**:
  - 화면 우측/하단에서 `[교사 모드]` 패널 오픈 (언제든 닫기/해제 가능).
  - **전 씬 즉시 이동**: `도입` / `1연` / `2연` / `3연` / `4연` / `5연` / `3중 상징 렌즈` / `2행 은유 카드` / `결과·디브리핑`.
  - **시연 보조 토글**: `관찰 도감 5종 모두 열람`, `헌신의 결 0~4단계 미리보기`, `어조 3종 즉시 비교`, `진행 초기화`.
  - 학생이 실수로 열지 않도록 일반 HUD에는 교사 버튼을 노출하지 않는다.

### 8.2 `localStorage` 상태 스키마
- 키 이름: **`jihak-kr-01-narutbae:progress-v1`** (공통 규칙 네임스페이스 준수)
- 저장 데이터:
  - `currentScene`: 현재 씬 ID
  - `grainLevel`: 헌신의 결 단계 (`0`~`4`)
  - `toneCompleted`: 연별 어조 조율 완료 여부 (`{ s2: boolean, s3: boolean, s4: boolean }`)
  - `contrastPlaced`: 대조의 저울 배치 상태
  - `observationsFound`: 세밀 관찰 5종 발견 ID 배열
  - `lensesViewed`: 3중 상징 렌즈 열람 배열 (`['lover', 'nation', 'buddhism']`)
  - `selectedLens`: 결과 카드 인장으로 선택한 내 시선 (`'lover' | 'nation' | 'buddhism' | null`)
  - `metaphorCard`: `{ target, selfMetaphor, youMetaphor, similarity, authorName, stamped }`
  - `muted`: 음소거 상태, `startedAt` / `completedAt`

1. **상단 영역 — 나만의 2행 은유 시집 카드 (1926년 한지 판형)**

#### 수업용 디브리핑 질문 4선 (결과 화면 표시 · 복사 가능)
1. **[교과서 활동 6-(2) 연계 — 「배를 매며」 비교]** 교과서에서 함께 배운 장석남 「배를 매며」의 '배'와 한용운 「나룻배와 행인」의 '배'는 모두 '사랑'과 관련된 상징이지만, 그 의미와 태도는 어떻게 다를까요?
2. **[상징의 다의성 — 친구와 비교]** 나는 결과 카드에 세 가지 시선(연인 · 조국 · 불교의 중생/부처) 중 무엇을 찍었나요? 다른 시선을 고른 친구와 서로의 근거를 나눠 봅시다.
3. **[어조의 효과]** 어조 조율기에서 원망체·건조체로 바꾸었을 때와 원문 경어체(`-ㅂ니다`, `-가십니다그려`, `-아요`)를 들었을 때, 화자의 태도가 어떻게 다르게 느껴졌나요?
4. **[서정적 표현 공유]** 내가 만든 2행 은유 카드(`나는 ___ / 당신은 ___`)를 친구에게 보여 주고, 어떤 점이 참신하거나 공감이 갔는지 댓글·소감을 나눠 봅시다.
